# Flipora mobile store submission

Flipora already includes an Expo/React Native mobile shell in this `mobile/` folder. The app loads the production marketplace at `https://shop-flipora.netlify.app`, so marketplace fixes and listing updates remain synchronized with the mobile app.

## App identity

- App name: Flipora
- Android package: `com.flipora.marketplace`
- iOS bundle identifier: `com.flipora.marketplace`
- Version: 1.0.0
- Category: Shopping / Marketplace

## Public store URLs

- Website: https://shop-flipora.netlify.app
- Privacy policy: https://shop-flipora.netlify.app/privacy.html
- Terms: https://shop-flipora.netlify.app/terms.html
- Support: https://shop-flipora.netlify.app/support.html

## Build with Expo EAS

From the repository:

```bash
cd mobile
npm install
npx eas login
npx eas build:configure
```

Android test APK:

```bash
npx eas build --platform android --profile preview
```

Production Android App Bundle and iOS archive:

```bash
npx eas build --platform all --profile production
```

## Google Play Console

1. Create the Flipora app in Google Play Console.
2. Use `com.flipora.marketplace` as the package name.
3. Complete app access, ads declaration, content rating, target audience, data safety, privacy policy, and store listing.
4. Upload the production `.aab` generated by EAS.
5. Add phone/tablet screenshots and a 512x512 Play Store icon.
6. Add a non-admin reviewer/test account if login is required for review.
7. Complete closed testing if required by the Google Play account before production release.

## Apple App Store Connect

1. Enroll in the Apple Developer Program and create the Flipora App ID for `com.flipora.marketplace`.
2. Create the Flipora app record in App Store Connect.
3. Complete App Privacy, age rating, support URL, privacy URL, category, description, screenshots, and review information.
4. Build the production iOS app with EAS using the Apple Developer account.
5. Submit the build to App Store Connect, select it for the release, and send it for Apple review.
6. Provide a non-admin reviewer/test account if login is required.

## Review testing before submission

Test these flows on real Android and iPhone devices:

- Create account and email verification
- Sign in and password reset
- Seller profile and profile picture
- Listing photo upload/camera selection
- Seller video upload/playback
- Listing details and multiple images
- Buyer-to-seller messages
- Lifetime seller membership checkout
- Membership cancellation with no lifetime-fee refund
- Stripe Connect seller onboarding and return to Flipora
- Buyer checkout and order confirmation
- External phone/email/map links

## Store-review note

The mobile app currently uses a native React Native shell around the Flipora web marketplace. Apple may require apps to provide enough app-like functionality beyond a simple website wrapper under its minimum-functionality review rules. Before the iOS production submission, verify that the current marketplace features, camera/photo access, messaging, account tools, checkout, and mobile navigation provide sufficient app-specific value. If Apple requests more native functionality, migrate the highest-use flows into native React Native screens instead of only the embedded marketplace.

## Credentials

Never commit Expo tokens, Google service-account keys, Apple passwords, signing certificates, provisioning profiles, Stripe secret keys, or store credentials to GitHub. Use Expo EAS credential storage and/or repository secrets.
